# B3Networks Partner Product Directory — Offline Guide

This directory contains the complete B3Networks Partner Product Directory optimized to run **100% offline without an internet connection**.

---

## 🚀 Quickest Way to Run (No Server, No Setup)

Simply **double-click** the file:
```
b3networks-offline.html
```
- It is a **self-contained standalone HTML file**.
- It bundles all styles, scripts, and product catalog data (31+ products) inside a single file.
- Works in **any web browser** (Chrome, Safari, Edge, Firefox, Brave) on Mac, Windows, Linux, iPad, or Android.
- Zero external font calls, zero CDNs, zero dependencies.

---

## 📂 Multi-Page Version

If you prefer navigating between separate pages:
1. Double-click `index.html` to open the directory.
2. Click any product name to view its detailed specifications and sales pitch on `product.html`.
3. Use the search box to instantly filter products by name in real time.
